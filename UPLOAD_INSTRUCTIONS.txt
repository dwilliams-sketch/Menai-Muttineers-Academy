MENAI MUTTINEERS ACADEMY V1.3 — STORAGE RULES FIX

This fixes the Storage Rules publish error caused by paths written as:
  /profiles/{uid}.jpg
  /dogs/{dogId}.jpg

Firebase Storage does not allow a wildcard to be embedded inside a path segment.

NEW SECURE PATHS
  profiles/{uid}/profile.jpg
  dogs/{dogId}/profile.jpg

STEP 1 — FIREBASE
Open storage.rules from this patch and paste it into:
Firebase -> Storage -> Rules
Then click Publish.
If Firebase asks for cross-service permissions, choose Attach permissions.

STEP 2 — GITHUB
Upload the CONTENTS of this patch to the root of your existing GitHub repository.
Replace/update matching files.
