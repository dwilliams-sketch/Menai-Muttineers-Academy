MENAI MUTTINEERS ACADEMY V1.3 — FIREBASE DEPENDENCY FIX

WHY THIS PATCH EXISTS
GitHub resolved firebase_auth 6.6.0 automatically. That very recent dependency
failed inside its Android/Kotlin source during the build.

This patch pins the FlutterFire packages to a single known-compatible release set.

UPLOAD
1. Upload the CONTENTS of this folder to the ROOT of the existing GitHub repository.
2. Replace/update matching files.
3. Commit with:
   Pin Firebase packages for V1.3 build
4. GitHub Actions should automatically start a new build.

If Windows hides .github, update .github/workflows/build-apps.yml manually as before.
The workflow change is only for 7-day artifact retention; the build can still work
without that workflow change.

NO FIREBASE CONSOLE / FIRESTORE CHANGES ARE NEEDED FOR THIS PATCH.

Version: 1.3.0+9
